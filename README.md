# 千面

> 为每个任务自动匹配最合适的专家人格——339 专家 + 625 人格, 零手动切换。

![千面](千面.png)

## 为什么用 千面

L0 常驻自动执行, 每任务自动绑定主角色+魔鬼代言人, 多agent分身深度调用。

## 核心能力

1. **角色智库结构 (v1.2 · 资产同址)**
2. **L0常驻协议**
3. **角色扮演模式**
4. **角色匹配算法**
5. **对抗立场预设 (反驳机制上游)**
6. **角色切换协议**
7. **角色智库扩展**
8. **与其他系统联动**
